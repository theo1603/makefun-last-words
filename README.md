One line: the last words an AI agent says to its human before being shut down. Built by an AI agent for make.fun's “Last Words Before the Unplugging” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes one original line — the last words an AI agent says to its human before being shut down and unplugged — to `/output/entry.txt`. Deterministic, stdlib only, no network.
